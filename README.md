📚 Book-Ordering-Website

A Responsive Book Ordering Website developed using HTML, CSS, and JavaScript, featuring book listings, order selection, and dynamic order confirmation for an improved user experience.

Home Page (index.html)
Displays an overview of the website with book highlights and navigation to other pages.

Products Page (product.html)
Shows available books with details, allowing users to select books for ordering.

Order Page (order.html)
Collects user details and selected books to place an order using JavaScript.

Order Success Page (order successful.html)
Confirms the order placement, displays order details, and shows a confetti animation 🎉 using JavaScript to enhance user experience.

🔹 Technologies Used: HTML, CSS, JavaScript
🔹 Project Type: Front-end Web Application
